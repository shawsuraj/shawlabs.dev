House rules

How the lab works.

  1. The data decides.No hardcoded favourites. On World Chaos Map, identical news about two countries must give identical scores, and a test enforces it.
  2. Rules before models.A simple rule I can explain ships before anything clever. Baselines first, then something better if it earns it.
  3. Show the working.Every product ships with documentation on how it works and where it falls short.
  4. Respect the source.robots.txt is honoured. Known propaganda outlets are blocked before they reach the pipeline.
  5. Accuracy before growth.When the numbers look wrong, the fix comes before the next feature or the next post.
  6. Ship early, write it down.Real enough to be useful beats ready. Then a note on what I learned.

On building in public

Dec 2025 · process, building

I have been shipping side projects for years without telling anyone.

The fear is not judgement. It is shipping something unfinished and having that be the first impression. But the problem with waiting until something is ready is that ready never arrives.

So this lab is an experiment in the opposite: show the scaffolding. Write decisions down as they are made. The code is not perfect. The ideas are not fully formed.

The bar is not "good enough to share". The bar is "real enough to be useful to someone".

World Chaos Map started as a weekend experiment I posted in a Discord. It is now the most interesting thing I have built. That would not have happened if I had waited.
